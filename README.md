# Momsflöde

Pedagogisk statisk webbsida som steg för steg förklarar hur moms rör sig när ett svenskt företag (C.se) köper från svenska och utländska leverantörer och säljer till utlandet.

## Öppna

Öppna filen i webbläsaren:

```bash
open momsmodell.html
```

Eller dubbelklicka på [`momsmodell.html`](momsmodell.html). Inget byggsteg eller server behövs — allt ligger i en enda HTML-fil.

## Vad sidan visar

1. Introduktion till momslogiken  
2. Aktörerna A.se, B.com, C.se, D.com och Skatteverket  
3. Inköp från A.se — belopp **inklusive** moms  
4. Inköp från B.com — belopp **exklusive** moms, redovisning till Skatteverket  
5. Försäljning till D.com — export utan moms  
6. Momsnetto för C.se + möjlighet att ändra beloppen live  
7. Skatteverkets inkomster och utgifter för hela exemplet
